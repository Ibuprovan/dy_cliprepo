## 发现并修复的问题

### 问题 1: Playwright 浏览器未安装

**现象**: 测试脚本报错 `Executable doesn't exist`

**解决**: 运行 `playwright install chromium`

### 问题 2: 前端服务未启动

**现象**: 测试脚本无法访问 http://localhost:5173

**解决**: 手动启动前端服务 `npm run dev`

### 问题 3: Unicode 编码错误

**现象**: 测试脚本中的 emoji 字符在 Windows GBK 编码下无法显示

**解决**: 将 emoji 替换为 ASCII 文本 `[PASS]`、`[FAIL]`、`[ERROR]`

### 问题 4: 视频列表选择器不匹配

**现象**: 测试脚本中的选择器 `table, [class*='video'], [class*='list']` 无法匹配空状态下的视频列表区域

**解决**: 更新选择器，添加 `div:has-text('暂无视频')` 来匹配空状态提示
