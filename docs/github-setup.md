## 操作步骤

1. 访问 https://github.com/Ibuprovan/dy_cliprepo
2. 点击右侧的 ⚙️ 图标（Settings）
3. 在 "General" 页面的 "Repository name" 下方找到 "Description" 输入框
4. 粘贴上述描述
5. 在 "Topics" 输入框中添加上述主题标签
6. 点击 "Save changes" 按钮
